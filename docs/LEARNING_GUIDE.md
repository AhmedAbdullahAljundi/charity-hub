### 📚 ما تحتاج تعلمه (What You Need to Learn)

- State Management (useState, useEffect, useContext)
- Props and Props Drilling
- Event Handling
- Conditional Rendering
- Lists and Keys
- Forms and Controlled Components
- **Resources:**
  - React Official Docs: https://react.dev
  - FreeCodeCamp React Course
  - YouTube: Traversy Media React Crash Course

**Next.js 14+ (Essential)**
- App Router (not Pages Router)
- Server Components vs Client Components
- Routing and Navigation
- Data Fetching
- API Routes
- **Resources:**
  - Next.js Official Docs: https://nextjs.org/docs
  - YouTube: Next.js 14 Tutorial by Traversy Media

**Tailwind CSS (Essential)**

- Responsive Design
- RTL Support
- **Resources:**
  - Tailwind CSS Official Docs: https://tailwindcss.com/docs
  - YouTube: Tailwind CSS Crash Course

**React Hook Form + Zod (Important)**

- Validation
- **Resources:**
  - React Hook Form Docs: https://react-hook-form.com

**Zustand (Important)**

## أفضل برامج AI (Best AI Tools)

### للفرونت (Frontend)

**1. Cursor (Recommended)**
- Best for: Full-stack development
- Features: Code completion, chat, context awareness
- Price: Free tier available, paid plans
- **Why it's best**: Understands your entire codebase, excellent for React/Next.js

**2. GitHub Copilot**
- Best for: Code completion
- Features: Inline suggestions, chat
- Price: $10/month
- **Why it's good**: Great integration with VS Code

**3. ChatGPT (GPT-4)**
- Best for: Explaining concepts, debugging
- Features: Code explanation, problem solving
- Price: $20/month for GPT-4
- **Why it's good**: Best for learning and understanding code

**4. Claude (Anthropic)**
- Best for: Long context, documentation
- Features: Large context window, good for reading code
- Price: Free tier, paid plans
- **Why it's good**: Excellent for understanding large codebases

### للباك (Backend)

**1. Cursor (Recommended)**
- Best for: Full-stack, backend logic
- Features: Understands database schemas, API design
- **Why it's best**: Context-aware, understands Prisma, Express patterns

**2. ChatGPT (GPT-4)**
- Best for: Business logic, algorithms
- Features: Complex problem solving
- **Why it's good**: Great for PMT scoring, medical eligibility logic

**3. GitHub Copilot**
- Best for: Code completion in backend
- Features: Suggests Express routes, Prisma queries
- **Why it's good**: Fast code generation

**4. Codeium**
- Best for: Free alternative
- Features: Code completion, chat
- Price: Free
- **Why it's good**: Good free option

### التوصية النهائية (Final Recommendation)

**For Learning:**
1. **ChatGPT (GPT-4)** - Best for understanding concepts
2. **Claude** - Best for reading and understanding documentation

**For Development:**
1. **Cursor** - Best overall (Frontend + Backend)
2. **GitHub Copilot** - Best for quick code completion

**Best Combination:**
- **Cursor** for daily development (understands your codebase)
- **ChatGPT** for learning and complex problem solving
- **Claude** for reading long documentation

## خطة التعلم (Learning Plan)

### الأسبوع 1-2: React Basics
- Learn React fundamentals
- Build simple components
- Practice with hooks

### الأسبوع 3: Next.js
- Learn Next.js App Router
- Build a simple Next.js app
- Understand routing

### الأسبوع 4: Tailwind CSS
- Learn Tailwind utilities
- Build responsive layouts
- Practice RTL support

### الأسبوع 5: Backend Basics
- Learn Node.js
- Learn Express.js
- Build simple API

### الأسبوع 6: Database
- Learn PostgreSQL basics
- Learn Prisma ORM
- Build database schema

### الأسبوع 7-8: Integration
- Connect Frontend to Backend
- Implement authentication
- Build full features

## نصائح للتعلم (Learning Tips)

1. **Practice Daily**: Code every day, even 30 minutes
2. **Build Projects**: Don't just read, build
3. **Read Documentation**: Official docs are your best friend
4. **Join Communities**: Stack Overflow, Reddit, Discord
5. **Use AI Wisely**: Use AI to learn, not just to copy code
6. **Debug Yourself**: Try to fix errors before asking for help
7. **Read Code**: Read other people's code on GitHub
